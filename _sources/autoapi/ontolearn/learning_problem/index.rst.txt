   .. py:method:: encode_kb(kb: ontolearn.abstracts.AbstractKnowledgeBase) -> EncodedPosNegLPStandard

      Provides the encoded learning problem (lp), i.e. the class containing the set of OWLNamedIndividuals
      as follows:
          kb_pos --> the positive examples set,
          kb_neg --> the negative examples set,
          kb_all --> all lp individuals / all individuals set,
          kb_diff --> kb_all - (kb_pos + kb_neg).
      :param kb: The knowledge base to encode the learning problem.
      :type kb: PosNegLPStandard

      :returns: The encoded learning problem.
      :rtype: EncodedPosNegLPStandard
